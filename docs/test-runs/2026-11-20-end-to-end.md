# End-to-end test run - 2026-11-20: onboarding to salary hike

The whole HR flow clicked through the real app, as each person would: company set-up, roles, employees added directly
(HR Head, HR Ops, Manager, IT), employees onboarded through the full offer -> joining form -> joining process (Admin,
HR), then HOD appointments, approval chains, a job change and a salary revision approved by each approver logging in.

- **How:** a visible Chrome driven over the DevTools protocol (real clicks and typing); web http://localhost:5180,
  API :5200, worker running. Mail is LIVE (Outlook SMTP); every e-mail field uses the tester's own address
  (prateekkumarsingh9955@gmail.com) and every one-time code is typed by the tester, never read by the test.
- **Who logs in:** SUPERADMIN (quick login), then each new employee with their own login. Passwords are not kept here.
- **Screenshots** (named in the "Shot" column) were kept outside the repository and are not part of this file.
